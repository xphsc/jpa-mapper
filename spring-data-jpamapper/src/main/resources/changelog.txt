spring-data-jpamapper 2.x Changelog
===================================
Changes in version 2.0.4
---------------------------------------------
* Upgrade spring-data-jpa to 2.2.13.RELEASE
* Upgrade hibernate version to 5.5.9.Final
---------------------------------------------

---------------------------------------------
* Writing SQL Insert  by adding SQL @NativeInsert  and @NativeInsertProvider annotations
* Writing SQL Update  by adding SQL @NativeUpdate  and @NativeUpdateProvider annotations
* Writing SQL DELETE  by adding SQL @NativeDelete  and @NativeDeleteProvider annotations
* Optimize the code of the NativeSQL RepositoryQuery class

* Writing SQL queries by adding SQL annotations
* Fix the bug Invalid annotation for data jpa @Param

Changes in version 2.0.1
